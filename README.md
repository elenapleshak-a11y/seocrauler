# Web Crawler

Простой веб-краулер для сбора всех страниц сайта.

## Функциональность

- Ввод URL сайта для анализа
- Автоматический обход всех внутренних ссылок
- Отображение прогресса краулинга
- Скачивание результатов в формате CSV
- Ограничение на тот же домен
- Фильтрация файлов и некорректных ссылок

## Использование

1. Откройте `index.html` в браузере
2. Введите URL сайта (например, `https://example.com`)
3. Нажмите "Собрать список Страниц"
4. Дождитесь завершения процесса
5. Скачайте CSV файл с результатами

## Ограничения

- Из-за CORS политики браузеров используется proxy
- Глубина обхода ограничена для демонстрации
- Работает только с публично доступными сайтами

## Технологии

- Pure JavaScript
- HTML5
- CSS3
